A calm home for your daily notes

jara is a local-first notes app for macOS. One page a day, plain Markdown, stored in a folder you own. Optional GitHub sync keeps it backed up and in step across your Macs.

Download for Mac

Requires macOS on Apple Silicon (M1 or newer). It's free while in beta.

First time opening jara

The beta isn't signed by Apple yet, so macOS asks before opening it the first time. This is a one-time step.

  1. Open the downloaded .dmg and drag jara into Applications.
  2. In Applications, right-click jara and choose Open. Don't double-click it the first time.
  3. Click Open in the dialog. macOS remembers your choice, so it opens normally from then on.

If macOS says the app is "damaged," that's just the download flag. Open Terminal and run xattr -cr /Applications/jara.app, then open it again.
